## Project Notes

This project's notes live outside the repository, in `{{NOTES_DIR}}`. Read and write there freely:

- `PROJECT.md` — the rules defined for this project (it takes the place of `.instructions/PROJECT.md`).
- `notes/` — notes and analyses.
- `plans/` — implementation plans.
- `references/` — downloaded or predefined reference material.

Never copy files from this folder into the repository, and never commit them.
