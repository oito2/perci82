# Documentação do Perci82

🌐 [English](../en/index.md) | **Português** | 🏠 [Voltar ao Leiame](leiame.md)

O Perci82 são dois aplicativos desktop para Linux: o **Perci82 System** administra o sistema operacional — pós-instalação, atualização do sistema e dos aplicativos, fontes, templates de arquivos e aplicativos Flatpak — e o **Perci82 Dev** prepara o ambiente de desenvolvimento. Os dois leem e gravam a mesma pasta `~/.perci`. Estas páginas tratam do Perci82 System; as do Perci82 Dev chegam com a primeira versão dele.

## 🚀 Primeiros passos

- [Instalar o Perci82 System](system/installation.md) — requisitos, script de instalação, instalação manual, compilação a partir do código-fonte e atualizações.
- [Desinstalar o Perci82 System](system/uninstallation.md) — o que a instalação coloca no sistema e como remover.
