# Perci82 Documentation

🌐 [Português](../pt-br/index.md) | **English** | 🏠 [Back to README](../../README.md)

Perci82 is two Linux desktop apps: **Perci82 System** manages the operating system — post-install setup, system and app updates, fonts, file templates and Flatpak apps — and **Perci82 Dev** sets up the development environment. Both read and write the same `~/.perci` folder. These pages cover both apps.

- [Installing Perci82 System](system/installation.md) — requirements, the install script, manual install, building from source and updates.
- [Uninstalling Perci82 System](system/uninstallation.md) — what installing puts on the system and how to remove it.
- [Installing Perci82 Dev](dev/installation.md) — requirements, the install script, manual install, building from source and updates.
- [Uninstalling Perci82 Dev](dev/uninstallation.md) — what installing and the app's screens leave on the system, the backups and how to remove it.
