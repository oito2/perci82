# Perci82 Documentation

🌐 [Português](../pt-br/index.md) | **English** | 🏠 [Back to README](../../README.md)

Perci82 is two Linux desktop apps: **Perci82 System** manages the operating system — post-install setup, system and app updates, fonts, file templates and Flatpak apps — and **Perci82 Dev** sets up the development environment. Both read and write the same `~/.perci` folder. These pages cover Perci82 System; Perci82 Dev's pages come with its first release.
